## Task 1: Add queryAll method to TS Database class (db.ts)

<read_first>

- packages/zqlite/src/db.ts
- packages/zqlite-rs/index.d.ts
  </read_first>

<action>
Add a `queryAll` method to the TS `Database` class in `db.ts` that delegates to the Rust implementation:

```typescript
queryAll<T = Record<string, unknown>>(
  sql: string,
  params: unknown[],
  columnTypes: Record<string, string>,
  tableName: string,
): T[] {
  return this.#db.queryAll(sql, params, columnTypes, tableName) as T[];
}
```

This goes in the public methods section of the Database class. The method delegates directly to `this.#db.queryAll(...)` where `this.#db` is the Rust Database instance.

Also update the `index.d.ts` for zqlite-rs to include the queryAll signature if it's not auto-generated properly by napi.
</action>

## Task 2: Build columnTypes map in TableSource

<read_first>

- packages/zqlite/src/table-source.ts
- packages/zqlite/src/query-builder.ts
  </read_first>

<action>
TableSource needs to provide `columnTypes` to `queryAll`. The column schema is available in `this.#columns` (a `Record<string, SchemaValue>`). Each `SchemaValue` has a `type` field (`"string" | "number" | "boolean" | "null" | "json"`).

Add a private cached property that builds the column types map once:

```typescript
#columnTypesMap: Record<string, string> | undefined;

get #columnTypes(): Record<string, string> {
  if (!this.#columnTypesMap) {
    this.#columnTypesMap = {};
    for (const [name, schema] of Object.entries(this.#columns)) {
      this.#columnTypesMap[name] = schema.type;
    }
  }
  return this.#columnTypesMap;
}
```

Place this near the other private fields (around line 120-130 area where other `#` fields are defined).
</action>

## Task 3: Replace #fetch hot path with queryAll

<read_first>

- packages/zqlite/src/table-source.ts
  </read_first>

<action>
In `#fetch()` method (around line 283-361), replace the iterate + mapFromSQLiteTypes pattern with queryAll.

**Current pattern (lines ~289-293):**

```typescript
const cachedStatement = this.#stmts.cache.get(sqlAndBindings.text);
cachedStatement.statement.safeIntegers(true);
const rowIterator = cachedStatement.statement.iterate<Row>(
  ...sqlAndBindings.values,
);
```

**Then later uses `#mapFromSQLiteTypes` generator.**

**Replace with:**

```typescript
// Use Rust queryAll for the hot path (all row iteration stays in Rust)
// Fall back to iterate path when debug delegate is present (for test compatibility)
let rows: Iterable<Row>;
if (this.#delegate) {
  // Debug path: uses iterate() so test at line 970 (iterator close test) works
  const cachedStatement = this.#stmts.cache.get(sqlAndBindings.text);
  cachedStatement.statement.safeIntegers(true);
  const rowIterator = cachedStatement.statement.iterate<Row>(
    ...sqlAndBindings.values,
  );
  rows = this.#mapFromSQLiteTypes(
    columns,
    rowIterator,
    cachedStatement,
    sqlAndBindings.text,
  );
} else {
  // Hot path: single FFI call, Rust handles all row iteration + type conversion
  rows = this.#db.queryAll(
    sqlAndBindings.text,
    sqlAndBindings.values,
    this.#columnTypes,
    this.#table,
  );
}
```

Where `this.#db` is the Database instance. TableSource already has access to the database via `this.#stmts` or the constructor. Need to store a direct reference.

**Store db reference:** Add `#db: Database` field. In the constructor, store the Database instance (it's passed as the first arg or available from the Statements object).

Look at TableSource constructor to find how db is accessed. The constructor receives `db: Database` (or `stmts: Statements` which has `.db`). Store it:

```typescript
readonly #db: Database;
// In constructor:
this.#db = db;  // or stmts.db depending on actual constructor signature
```

**Remove the try/finally block** around the iterate path for the non-debug case (since queryAll doesn't need iterator cleanup). Keep it for the debug path.

The `generateWithOverlay` / `generateWithOverlayUnordered` functions accept `Iterable<Row>`, and a JS array is iterable, so feeding `queryAll` result directly works.
</action>

<acceptance_criteria>

- packages/zqlite/src/table-source.ts `#fetch` method contains `this.#db.queryAll`
- Debug path (when `this.#delegate` exists) still uses `statement.iterate()`
- Non-debug path uses `queryAll` with `this.#columnTypes` and `this.#table`
- `#db` field exists on TableSource class
  </acceptance_criteria>

## Task 4: Replace getRow with queryAll

<read_first>

- packages/zqlite/src/table-source.ts
  </read_first>

<action>
In `getRow()` method (around line 506-519), replace `statement.get()` + `fromSQLiteTypes` with queryAll:

**Current:**

```typescript
const row = cache.use(sql, stmt => {
  stmt.safeIntegers(true);
  return stmt.get<Row>(...values);
});
if (row) {
  return fromSQLiteTypes(this.#columns, row);
}
return undefined;
```

**Replace with:**

```typescript
const rows = this.#db.queryAll<Row>(
  sql,
  values,
  this.#columnTypes,
  this.#table,
);
return rows.length > 0 ? rows[0] : undefined;
```

This is simpler and keeps the row conversion in Rust.
</action>

- Returns `rows[0]` or `undefined`
- No longer calls `fromSQLiteTypes` in getRow
