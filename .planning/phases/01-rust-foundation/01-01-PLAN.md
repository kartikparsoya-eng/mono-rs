# Plan 01-01: Scaffold napi-rs Rust Crate

<objective>
Create the `packages/zqlite-rs/` package with Cargo.toml, package.json, build.rs, and a minimal napi-rs export that compiles and loads in Node.js. This validates the entire build toolchain before implementing business logic.
</objective>

<must_haves>
- [ ] `packages/zqlite-rs/Cargo.toml` exists with napi-rs and rusqlite dependencies
- [ ] `packages/zqlite-rs/package.json` exists with napi build scripts
- [ ] `cargo build` succeeds in `packages/zqlite-rs/`
- [ ] `npm run build` produces a `.node` binary
- [ ] A trivial napi export (e.g., `fn hello() -> String`) can be called from Node.js
- [ ] rusqlite with bundled SQLite compiles successfully
</must_haves>

<task id="01-01-01">
<title>Create Cargo.toml with napi-rs and rusqlite dependencies</title>

<read_first>
- packages/zqlite/package.json (understand naming conventions)
- .planning/phases/01-rust-foundation/01-RESEARCH.md (stack decisions)
- .planning/phases/01-rust-foundation/01-CONTEXT.md (D-01, D-04 decisions)
</read_first>

<action>
Create `packages/zqlite-rs/Cargo.toml`:

```toml
[package]
name = "zqlite-rs"
version = "0.0.0"
edition = "2021"

[lib]
crate-type = ["cdylib"]

[dependencies]
napi = { version = "3", features = ["napi9"] }
napi-derive = "3"
rusqlite = { version = "0.33", features = ["bundled", "backup", "blob", "hooks", "trace"] }

[build-dependencies]
napi-build = "2"

[profile.release]
lto = true
strip = "symbols"
```

Create `packages/zqlite-rs/build.rs`:

```rust
extern crate napi_build;

fn main() {
    napi_build::setup();
}
```

Create `packages/zqlite-rs/.cargo/config.toml` with platform-specific linker flags for napi-rs:

For macOS:
```toml
[target.x86_64-apple-darwin]
rustflags = ["-C", "link-arg=-undefined", "-C", "link-arg=dynamic_lookup"]

[target.aarch64-apple-darwin]
rustflags = ["-C", "link-arg=-undefined", "-C", "link-arg=dynamic_lookup"]
```
</action>

<acceptance_criteria>
- `packages/zqlite-rs/Cargo.toml` contains `napi = { version = "3"`
- `packages/zqlite-rs/Cargo.toml` contains `rusqlite = { version = "0.33"`
- `packages/zqlite-rs/Cargo.toml` contains `crate-type = ["cdylib"]`
- `packages/zqlite-rs/build.rs` contains `napi_build::setup()`
- `packages/zqlite-rs/.cargo/config.toml` contains `dynamic_lookup`
</acceptance_criteria>
</task>
