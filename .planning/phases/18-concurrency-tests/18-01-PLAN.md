<action>
Append the following tests inside the existing `#[cfg(test)] mod tests` block in `advance.rs` (before the closing `}` at line 1113):

1. **Helper function `sorted_row_changes`** — takes `&[RowChange]`, returns a new Vec sorted by `(query_id, row_key.to_string())` for order-independent comparison.

2. **`test_par_iter_determinism_20_pipelines_50_iterations`**:
   - Create 20 `PipelineConfig` entries (`q0`..`q19`), all with `source_tables: ["items"]`, `primary_key: ["id"]`
   - Vary filters across pipelines:
     - q0-q4: no filter (pass-through)
     - q5-q9: `{"op": "gt", "field": "val", "value": <i*10>}` (range filters)
     - q10-q14: `{"op": "eq", "field": "active", "value": true}` (equality)
     - q15-q17: `{"op": "in", "field": "category", "values": ["a","b"]}` (in-list)
     - q18-q19: `{"op": "and", "conditions": [{"op": "gt", "field": "val", "value": 0}, {"op": "eq", "field": "active", "value": true}]}` (compound)
   - Create 50 `Change` entries — mix of adds (no prev_values), edits (prev + next), and deletes (no next_value):
     - 30 adds with varied field values (`id: "r0".."r29"`, `val: 0..290 step 10`, `active: i%2==0`, `category: ["a","b","c"][i%3]`)
     - 10 edits (`id: "e0".."e9"` with prev and next values, changing `val`)
     - 10 deletes (`id: "d0".."d9"` with prev_values only)
   - Wrap changes in `Arc::new(changes)`
   - Run baseline: `pipelines.par_iter().flat_map(|p| process_pipeline(p, &changes_arc)).collect()`
   - Loop 50 times, collect result, sort both via `sorted_row_changes`, `assert_eq!` with iteration number in message
   - Also assert `baseline.len() > 0` to confirm test is actually exercising pipelines

3. **`test_par_iter_determinism_preserves_pipeline_order`**:
   - Create 10 pipelines with no filters, each with distinct `query_id` ("order_q0".."order_q9")
   - Create 5 add changes
   - Run once, verify that results appear grouped by pipeline order: all "order_q0" results appear before "order_q1", etc. (Rayon's IndexedParallelIterator guarantee)
   - Run 50x to confirm ordering stability

4. **`test_par_iter_empty_pipelines_no_panic`**:
   - Empty `Vec<PipelineConfig>`, 10 changes
   - `par_iter().flat_map().collect()` should produce empty Vec, no panic

5. **`test_par_iter_empty_changes_no_panic`**:
   - 20 pipelines, empty changes Vec
   - Should produce empty results, no panic
