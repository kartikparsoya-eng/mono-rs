## Goal

Test 3 complex join topologies through the pipeline driver's Rust-accelerated path: parent→child→grandchild (3-level), sibling joins (two children of same parent), and parent with EXISTS on child.

## Background

OPC-02 requires testing complex join topologies through the `rust_advance()` pipeline. These are pure test files — no production code changes. The tests verify that multi-level and sibling join structures produce correct hydration results and react correctly to data changes.
