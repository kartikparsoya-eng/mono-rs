# Plan 13-01: Rust Diff Reader

## Objective

Port the snapshot diff logic from `snapshotter.ts` into a pure Rust module in `zqlite-rs`.
Create a function that reads `_zero.changeLog2`, fetches prev/next row values from two
SQLite connections (prev and curr snapshots), handles RESET/TRUNCATE signals, filters
no-op changes, and returns a fully materialized `Vec<Change>`. This is the foundation
for Plan 13-02's Rayon fan-out -- all diff data must be read on the main thread before
parallel processing.

<action>
Create `packages/zqlite-rs/src/diff.rs` with the following:

1. **Types:**
   ```rust
   use std::collections::HashMap;
   use serde::{Serialize, Deserialize};

   pub type Row = HashMap<String, serde_json::Value>;

   #[derive(Debug, Clone, Serialize)]
   pub struct Change {
       pub table: String,
       pub prev_values: Vec<Row>,
       pub next_value: Option<Row>,
       pub row_key: serde_json::Value,
   }

   #[derive(Debug, Clone, Deserialize)]
   pub struct TableSpec {
       pub name: String,
       pub columns: Vec<String>,
       pub primary_key: Vec<String>,
       pub unique_keys: Vec<Vec<String>>,
       pub min_row_version: Option<String>,
   }

   #[derive(Debug, Clone, Deserialize)]
   pub struct ZqlSpec {
       pub columns: HashMap<String, ColumnSpec>,
   }

   #[derive(Debug, Clone, Deserialize)]
   pub struct ColumnSpec {
       #[serde(rename = "type")]
       pub col_type: String,
   }

   #[derive(Debug, Clone, Deserialize)]
   pub struct TableAndZqlSpec {
       pub table_spec: TableSpec,
       pub zql_spec: ZqlSpec,
   }

   #[derive(Debug)]
   pub enum DiffError {
       Reset(String),
       Truncate(String),
       Unknown(String),
   }
   ```

2. **`read_changelog_entries()` function:**
   Takes a `&rusqlite::Connection` (curr snapshot), `prev_version: &str`, returns an iterator/vec of changelog rows.
   Uses the same SQL as `changes_since_buf`: `SELECT stateVersion, "table", rowKey, op FROM "_zero.changeLog2" WHERE stateVersion > ? ORDER BY stateVersion, pos LIMIT ? OFFSET ?`.
   Batches in groups of 500. Returns `Vec<(String, String, serde_json::Value, String)>` -- (stateVersion, table, rowKey, op).

3. **`get_row()` function:**
   Takes `conn: &rusqlite::Connection`, `table_spec: &TableSpec`, `row_key: &serde_json::Value`.
   Builds SQL: `SELECT {cols} FROM {table} WHERE {pk_col}=? AND ...`.
   Returns `Option<Row>` (HashMap of column name to serde_json::Value).
   Normalizes key order same as TS `normalizedKeyOrder`.

4. **`get_rows()` function:**
   Takes `conn`, `table_spec`, `unique_keys: &[Vec<String>]`, `row: &Row`.
   Filters out keys where any column value is null (matching TS NULL filter for SQLite OR optimization).
   Builds OR query: `SELECT {cols} FROM {table} WHERE (k1=? AND k2=?) OR (k3=?)`.
   Returns `Vec<Row>`.

5. **`from_sqlite_types()` function:**
   Takes `zql_spec: &ZqlSpec`, `row: &mut Row`, `table: &str`.
   Converts boolean columns (0/1 -> false/true), json columns (string -> parsed JSON).
   Modifies row in place matching TS `fromSQLiteTypes`.

6. **`read_diff()` -- main entry point:**
   ```rust
   pub fn read_diff(
       prev_conn: &rusqlite::Connection,
       curr_conn: &rusqlite::Connection,
       prev_version: &str,
       syncable_tables: &HashMap<String, TableAndZqlSpec>,
       all_table_names: &HashSet<String>,
       permissions_table: &str,
   ) -> Result<Vec<Change>, DiffError>
   ```
   Implements the full `Diff[Symbol.iterator]()` logic:
   - Reads changelog entries from curr_conn
   - For each entry: check RESET_OP ("r") / TRUNCATE_OP ("t") -> return DiffError::Reset/Truncate
   - Skip non-syncable tables (not in syncable_tables but in all_table_names)
   - Error on unknown tables
   - For SET_OP ("s"): fetch nextValue from curr_conn via get_row, fetch prevValues from prev_conn via get_rows
   - For delete: fetch prevValue from prev_conn via get_row
   - Filter no-ops (no prev, no next)
   - Check permissions table changes -> DiffError::Reset
   - Apply from_sqlite_types to all rows
   - Collect into Vec<Change>

Register module in `packages/zqlite-rs/src/lib.rs`: add `pub mod diff;`
</action>
