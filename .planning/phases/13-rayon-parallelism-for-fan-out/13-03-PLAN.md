# Plan 13-03: TS Integration + Fallback

## Objective

Wire `pipeline-driver.ts#advance()` to call `rust_advance()` instead of the TS generator
path. Serialize pipeline topology when pipelines are added/removed. Fall back to the
existing TS advance path for unsupported configurations (joins with state, scalar
subqueries). Map Rust error responses to `ResetPipelinesSignal`.

<action>
In `packages/zero-cache/src/services/view-syncer/pipeline-driver.ts`:

1. Import `rustAdvance` from the zqlite-rs napi module (same pattern as existing Rust imports).

2. Modify the `advance()` method (lines 635-658) to check `#useRustAdvance` first:
   ```typescript
   advance(timer: Timer) {
     assert(this.initialized(), '...');
     if (this.#useRustAdvance && this.#pipelineConfigs.size > 0) {
       try {
         return this.#rustAdvance(timer);
       } catch (e) {
         if (e instanceof ResetPipelinesSignal) throw e;
         this.#lc.warn?.(`Rust advance failed, falling back to TS: ${e}`);
         this.#useRustAdvance = false;
       }
     }
     // existing TS path unchanged below
     const diff = this.#snapshotter.advance(...);
     // ...
   }
   ```

3. Add private method `#rustAdvance(timer: Timer)`:
    - Call `this.#snapshotter.advanceWithoutDiff()` to get `{prev, curr}` Snapshot objects
    - Get numChanges via `curr.numChangesSince(prev.version)`
    - Gather arguments for `rustAdvance()`:
      - `dbPath`: from `curr.db.db.name` (the SQLite file path on the Database handle)
      - `syncableTablesJson`: `JSON.stringify(Object.fromEntries(this.#syncableTables))` (private field on PipelineDriver, type `Map<string, TableAndZqlSpec>`)
      - `allTableNamesJson`: `JSON.stringify([...this.#allTableNames])` (private field, type `Set<string>`)
      - `permissionsTable`: `this.#permissionsTable` (private string field set in constructor)
      - `pipelineConfigsJson`: `this.#serializePipelineConfigs()`
    - Read these fields by adding `read_first` reference to the constructor/field declarations
      in `pipeline-driver.ts` (around lines 50-120) where `#syncableTables`, `#allTableNames`,
      and `#permissionsTable` are declared.
    - Call `rustAdvance(dbPath, prev.version, curr.version, syncableTablesJson, allTableNamesJson, permissionsTable, pipelineConfigsJson)`
   - Parse JSON result
    - If `result.error_type` is "version_mismatch", retry once (re-call `advanceWithoutDiff()` to get fresh snapshots)
    - If `result.error_type` is "reset" or "truncate", throw `new ResetPipelinesSignal(result.error, result.error_type)`
   - Set new snapshot on all TableSources: `for (const table of this.#tables.values()) table.setDB(curr.db.db)`
   - Return `{ version: curr.version, numChanges, changes: result.changes }`

4. The fallback is implicit: `#useRustAdvance` is false for unsupported pipelines, and
   set to false on unexpected Rust errors.
</action>
