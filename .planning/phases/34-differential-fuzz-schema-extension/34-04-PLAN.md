<objective>
Extend the parity harness schema to production-shape density per D-09 (target: `apps/zbugs/shared/schema.ts`), adding rich production-relevant types (jsonb x2, timestamptz x2, numeric, nullable, composite, bigint) plus seed fixtures covering NULL semantics (D-11) and type-coercion boundaries (D-12).
