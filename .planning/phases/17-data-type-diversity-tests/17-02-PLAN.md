# Plan 17-02: Data Type Diversity Test Files

Create 4 test files covering JSON, NULL, Unicode, and boundary number data types.
Each file follows the dual-path Rust vs TS comparison pattern via `ZERO_DISABLE_RUST_IVM`.

## must_haves
- JSON round-trip test for nested objects and arrays (DAT-01)
- NULL handling in filters, joins, and sort keys produces identical Rust/TS results (DAT-02)
- Unicode strings (emoji, CJK, RTL, combining chars) work in equality and LIKE (DAT-03)
- Boundary numbers (MAX_SAFE_INTEGER, -0, large floats) pass without corruption (DAT-04)
- All tests use dual-path comparison (default Rust path + ZERO_DISABLE_RUST_IVM=1 TS path)
- No modifications to existing files
