**Channel sizing decision:** RESEARCH Open Q #1 + Pitfall 1 recommend `pipeline_count.max(1) + 1` rather than CONTEXT D-16's literal `pipeline_count`. The +1 guarantees the final ResetSignal/companion-Chunk slot exists even when all pipeline slots are occupied — eliminates the cancel-deadlock window for trivial cost. Documented in `advance_streaming` doc comment.

**Cancel-check cadence:** RESEARCH Open Q #2 — start with once-per-change at `advance.rs:1261` (top of `for change in changes.iter()` loop). If TEST-01 fails for big-pipeline scenarios, escalate to once-per-operator inside `push_through_ptrs` — fallback noted but ship once-per-change first.

**Coordinator pattern:** `std::thread::spawn` owns `rayon::scope(|s| { ... })`; one `s.spawn` per pipeline; each spawn wraps work in `panic::catch_unwind(AssertUnwindSafe(...))`; after scope joins, coordinator runs companion check + filters companion rows + sends final StreamItem then drops `tx`. AsyncTask-per-`next()` blocks on `rx.recv()` from a libuv worker thread.

       ```rust
       pub fn encode_chunk_buf(rows: &[RowChange]) -> Vec<u8> {
           use crate::advance::{encode_json_value, encode_str};

           // Pre-allocate generously (rough heuristic — 64 bytes per row average).
           let mut buf = Vec::with_capacity(5 + rows.len() * 64);

           // [u32 count LE]
           buf.extend_from_slice(&(rows.len() as u32).to_le_bytes());
           // [u8 flags=0] — Reserved per D-03; future telemetry bits go here.
           buf.push(0u8);

           // Per RowChange — MUST match the per-row layout in
           // encode_advance_result_buf so 31-02's decodeAdvanceChunkBuf (which
           // shares row-reader logic with decodeAdvanceResultBuf) decodes correctly.
           for change in rows {
               // [u8] change_type — same numeric mapping as buffered encoder
               // (0=add, 1=remove, 2=edit, 3=other) per decode-advance-buf.ts:32.
               let ct: u8 = match change.change_type.as_str() {
                   "add" => 0,
                   "remove" => 1,
                   "edit" => 2,
                   _ => 3,
               };
               buf.push(ct);

               // [u16 + bytes] query_id (encode_str writes u16 LE length + UTF-8)
               encode_str(&mut buf, &change.query_id);
               // [u16 + bytes] table
               encode_str(&mut buf, &change.table);
               // [json_value] row_key
               encode_json_value(&mut buf, &change.row_key);

               // [u8] has_row, then optional [u16 col_count][per col] block
               match &change.row {
                   None => buf.push(0u8),
                   Some(row_map) => {
                       buf.push(1u8);
                       let col_count = row_map.len() as u16;
                       buf.extend_from_slice(&col_count.to_le_bytes());
                       for (col_name, col_value) in row_map {
                           encode_str(&mut buf, col_name);
                           encode_json_value(&mut buf, col_value);
                       }
                   }
               }
           }

           buf
       }
       ```
