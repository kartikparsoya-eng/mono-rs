## Cross-Phase Integration

### Verified ✅
- **Fallback consistency**: All 4 Rust paths gated behind `USE_RUST_IVM` module-level constant
- **E2E flow**: addQuery → advance → rust_advance → diff read → Rayon fan-out → RowChange output
- **Error handling**: Rust errors permanently disable `#useRustAdvance`, fall through to TS path
- **Layer independence**: Operator-level Rust (phases 10-12) fires independently during TS advance path

### Issue Found ⚠️
- **INT-01 (Medium)**: Edit semantics mismatch in `advance.rs:280` — Rust uses `prev_values[0]` positional indexing while TS path uses `deepEqual` on primary keys. For filter-only queries this is unlikely to trigger (no multi-PK conflicts without joins), but should be fixed for correctness.
