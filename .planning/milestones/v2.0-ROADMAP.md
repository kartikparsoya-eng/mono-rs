# Milestone v2.0 — IVM Operators in Rust (Archived)

**Started:** 2026-04-20
**Completed:** 2026-04-21
**Tag:** `mono-rs/v2.0`

## Summary

Ported all performance-critical IVM operators (Filter, Take, Join, Exists) to Rust via napi-rs, added Rayon-based parallelism for pipeline fan-out, and integrated via delegate pattern with zero modifications to existing TS source in `packages/zql/`.

## Key Accomplishments

1. **Rust Filter + Take operators** — stateless predicate evaluation + in-memory HashMap state machine (Phase 10)
2. **Rust Join hot-path** — batch constraint matching, child push decisions in Rust (Phase 11)
3. **Rust Exists batch push** — correlated subquery acceleration (Phase 12)
4. **Rayon parallel fan-out** — `rust_advance()` drives entire advance loop for filter-only pipelines, `par_iter` over pipelines per diff change (Phase 13)
5. **Edge case testing + docs** — 6 integration tests, architecture docs, benchmark infrastructure (Phase 14)
6. **Correctness gap closure** — PK-based edit matching, dead code removal (Phase 15)
